notes: |
  This is the only launcher that needs Node: `react-x11/refresh/register`
  uses `module.registerHooks`, which bun does not implement, so it spawns
  `node` by name even when the deck is running under bun. Worth knowing if it
  is the one demo that fails on a strange machine.
  DEMO — 2 min, and the one to rehearse. Start it, click "count me" a few
  times, type something into the field, THEN press the edit button.
  The headline and its colour change; the count and the half-typed text do
  not. Say the pid out loud: same process, same window, same X11 connection.
  Better version if the room can see your editor: open
  examples/hot-demo-app.jsx on a second screen and save it yourself. The
  button is the one-projector fallback.
  The button cycles three variants and the third press restores the file, so
  the repo is clean afterwards.

# Fast Refresh, on a window the desktop owns

`node --import react-x11/refresh/register` and nothing else: no accept
handlers, no loader files to copy. Saving a file re-evaluates the modules
that changed and re-renders the components that came from them, **in place**.

count, and whatever is half-typed in the field.
