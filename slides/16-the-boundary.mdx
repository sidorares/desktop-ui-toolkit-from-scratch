# You cannot remove it. You can only place it.

The pixels are not yours. The display server owns them, so **something** has
to cross that gap — and every design we have looked at has a boundary in it,
including mine.

They differ in *where*, not in *whether*:

^^^

| the boundary sits between | and it is |
| --- | --- |
| **Electron** — your UI and the desktop | an IPC channel you invented, and you are its only implementer |
| **a binding** — your code and the widgets | a language bridge you cannot see into |
| **this** — you and the display server | a protocol specified in 1987 — extended many times, never broken — and the one you watched decode itself |

^^^

> So put it at the socket.

Below the wire is somebody else's problem — written down, forty years old,
and the same on every machine that speaks it.

Above the wire is **all yours.**

^^^

Which is a much bigger "all" than it sounds.

So: what does owning everything above a socket actually leave you to write?
