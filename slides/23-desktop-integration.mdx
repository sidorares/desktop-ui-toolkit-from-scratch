# The other half of belonging

The calendar was the desktop being **read** from. This is writing to it — and
it is the half a browser tab has no expression for at all.

| what the user sees | what you write |
| --- | --- |
| a count on the app icon | `useBadge(value)` |
| an icon in the tray, with a menu | `useTray({ icon, menu, onClick })` |
| the Dock icon's own menu | `useDockMenu(items)` |
| your menu, in the desktop's panel | `<MenuBar menus={…} />` |
| a banner that outlives every window | `useNotifier()` |
| "look at me" | `states={['demands_attention']}` |
| where a window may actually go | `useScreens().primary.available` |

Every one of them is **declared, not pushed** — a value a component holds
while it is mounted, cleared on the way out. There is no `clearBadge()` for
anybody to forget.

^^^

# One array, three destinations

`MenuBar`'s items are `com.canonical.dbusmenu`'s vocabulary. Not by
coincidence — **by design**, so that there is no second authoring model:

```jsx
const menus = [{ label: 'Slide', items: [
  { label: 'Next slide', onSelect: nav.next },
] }];
```

| the desktop | what becomes of that array |
| --- | --- |
| Plasma · Unity · `vala-panel-appmenu` | a registrar answers → exported over D-Bus |
| macOS | the same snapshot → `setMainMenu`. The real menu bar |
| stock GNOME | nobody owns the name → `<MenuBar>` draws it itself |

On macOS that one builder also fills the Dock menu and the tray's menu. And
the app branches on **the answer**, never on the platform:

```jsx
const exported = useGlobalMenu(menus);
if (exported) return null;
```

^^^

# …and where it is empty

The interesting rows are the missing ones, and they are not the ones you would
guess:

- **The tray is the most Linux-shaped thing on that list, and react-x11 has it
  only on macOS.** `useTray().available` is `false` on X11 — #353 is open
- **The badge is the mirror image.** A Dock tile takes any label; the
  freedesktop protocol underneath a Linux launcher carries a *count* and has
  no text field at all. So the `23 / 41` this deck is showing you appears
  **nowhere** on a Linux desktop — silently, and by design
- **`available` is an approximation, and says so.** `_NET_WORKAREA` is
  published for the whole virtual desktop, so per-monitor is a per-axis bound

A hook that quietly does nothing where the desktop has nothing is what makes
it safe to write unconditionally — which is why nothing in the first table
needed an `if (platform === …)` around it.
