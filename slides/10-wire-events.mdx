# One bit more, and it answers back

<Wire example="mousedown" />

`eventMask` is a 32-bit set inside the *same* `CreateWindow`. Asking for
clicks costs four bytes and no extra request — and every click comes back as
32 bytes the client never asked for, which is the half of the protocol that
is not request/reply at all.
