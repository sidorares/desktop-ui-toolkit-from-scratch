# node-x11 — June 2011

A pure-JavaScript X11 protocol client. No bindings, no `node-gyp`, no Xlib.

^^^

```js
const x11 = require('x11');
const display = await x11.createClient();
const wid = display.client.AllocID();
display.client.CreateWindow(wid, root, 0, 0, 400, 300);
display.client.MapWindow(wid);
```

^^^

That was fifteen years ago. It stayed a *protocol library* — you could
open a window, but you had to draw everything yourself.
