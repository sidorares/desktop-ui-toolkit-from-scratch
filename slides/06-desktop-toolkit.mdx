# Drawing rectangles is the easy 20%

A toolkit is what makes an application belong to the desktop it is running
on. Almost none of that is drawing.

^^^

- **Integration** — drag and drop with other apps, the global menu, file and
  print dialogs, permission prompts
- **Native look & feel** — the desktop's colour scheme, light/dark, reduced
  motion, increased contrast
- **Accessibility** — screen readers, magnifiers, alternative input methods
- **i18n / l10n** — the system's language, locale, date and number formats
- **Activation** — `myapp://` links launching, or focusing, the running app
- **Distribution** — packaging and updates

^^^

Every one of those is a **protocol you have to speak**, not a feature you
implement. That is the actual work.

^^^

> `<MenuBar menus={…}/>` hands its menu to the desktop's panel over
> `com.canonical.dbusmenu` where one exists, and draws the bar itself where
> none does.

Same line of JSX either way — because the array that draws the menu is the
array that serialises.
