# "Desktop UI toolkit" is a bigger claim than it sounds

Drawing rectangles is the easy part. A toolkit is what makes an app belong
to the desktop it runs on.

^^^

- **Integration** — drag and drop, global menu, file and print dialogs,
  permission prompts
- **Native look & feel** — standard controls, the desktop's colour scheme,
  light/dark, reduced motion, increased contrast
- **Accessibility** — screen readers, magnifiers, alternative input methods
- **i18n / l10n** — the system's language, locale, date and number formats
- **Activation** — `myapp://` links launching or focusing the running app
- **Distribution** — packaging, updates
