# The loop

^^^

1. **Draft** an app that wants something
2. Discover the **gap** — the thing every app would have to write itself
3. **Promote** it: from the app, to the components package, to core

^^^

`<Markdown>` exists because a chat UI needed it. Drag and drop moved into
core because a reorderable list and a file drop turned out to be the same
two props.

^^^

> earlier lived in the components package; between two `npm install`s it
> moved into core — because reading the user's calendar is something an app
> does *outside* its own windows, like the tray — and the migration was two
> import lines.
