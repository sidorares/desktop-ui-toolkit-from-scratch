# The debugger that ships with React

The component tree, the props and hook state behind each node, and a
profiler for the commits. In a browser it is an extension talking to the
page. Here it is the **standalone app**, and the backend talks to it over a
socket — which is why a renderer with no DOM gets it for nothing.

Two processes, because `REACT_X11_DEVTOOLS` is read before React's first

cannot inspect itself** — what opens is a second app, and the tree in that
window is its tree.
