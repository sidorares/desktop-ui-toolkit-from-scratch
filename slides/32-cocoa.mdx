# Then macOS happened

The same component tree, a different renderer underneath: Core Animation
layers instead of X11 windows.

^^^

- Two presenters — one drives X11, one drives CoreGraphics
- A layer per real window, everything else painted into it
- The same yoga layout, the same events, the same components

^^^

And the cost: the AppKit bridge is a **compiled module**.

^^^

> "No binary modules" was never the goal. It was a constraint that kept the
> design honest — and macOS was worth breaking it for.

Wayland and Windows are the same shape of problem.
