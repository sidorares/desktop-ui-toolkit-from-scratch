# It's all just bytes on a socket

The wire carries drawing, not pixels. Belonging to a desktop is a dozen
conversations, none of which involve a pixel. React's reconciler is a
protocol. DevTools is a protocol. The presenter is a protocol I wrote for
myself, which is the only reason there is a second backend.

And an Electron app is one too — it is just a protocol you had to invent.
